Vitrava Window Template

Thank you for purchasing Vitrava. This documentation guides you through installing, customizing brand elements, modifying color palettes, and deploying the template.

1. Overview & Features

Vitrava is a commercial-grade, multipage static HTML5 website template built with semantic HTML, modern vanilla JavaScript ES modules, and a dedicated architectural design system. It includes 51 standalone HTML files, including two distinct homepages, six service detail pages, six product detail pages, six project case studies, nine blog articles, and a complete six-page client installation portal.

3. Quick Start & Deployment

Vitrava is a zero-dependency static frontend template. You can:

  1. Double-click index.html to open the site directly in any modern browser without needing to run a build or server.
  2. Upload all files directly to any static web host: Apache, Nginx, Netlify, Vercel, GitHub Pages, or AWS S3.
  3. Or run locally using any standard command line web server: npx serve . or python -m http.server 3000.

4. Colors & Typography

To change theme colors, open assets/css/style.css and edit the :root CSS variables:

:root { --color-text-main: #17272E; /* Deep Graphite */ --color-bg-main: #F7FAF9; /* Frost White */ --color-surface: #FFFFFF; /* Pure White */ --color-primary: #087D8C; /* Ocean Teal */ --color-primary-hover: #066572; --color-accent: #DDEFEA; /* Sea Glass */ --color-highlight: #D8EC8C; /* Soft Citron */ --color-text-muted: #61747B; /* Cool Slate */ --color-border: #DCE5E5; }

5. Energy Savings Calculator

The calculator engine is located in assets/js/calculator.js. You can customize the mathematical assumptions (annual inflation rate, climate load fractions, and baseline U-factors) in the MODEL_ASSUMPTIONS object at the top of the file.

7. Connecting Forms to a Backend API

All forms feature client-side validation in assets/js/main.js. To send submissions to an actual email service or server endpoint:

// In assets/js/main.js: fetch('/api/contact', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name, email, phone, message }) }) .then(res => res.json()) .then(data => { VitravaToast.show('Thank you! Inquiry received.', 'success'); });
